\# HR Attrition Analytics Dashboard



\## Overview

This project is an interactive HR Attrition Analytics Dashboard developed using Power BI.



The dashboard helps analyze employee attrition trends, job roles, salary slabs, education fields, and demographic insights to support HR decision-making.



\---



\## Key Insights

\- Overall employee attrition analysis

\- Attrition by age group

\- Attrition by salary slab

\- Attrition by job role

\- Attrition by education field

\- Gender-based attrition analysis



\---



\## Tools \& Technologies Used

\- Power BI

\- DAX Queries

\- Excel / CSV Dataset



\---



\## Dashboard Features

\- Interactive KPI Cards

\- Dynamic Filters \& Slicers

\- Professional Visualizations

\- Business Intelligence Insights
